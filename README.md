## ✨ Features & Visual Aesthetics

1. **Interactive Neural Network Particle Canvas (60fps)**: Floating nodes in the hero section that gently repel and connect to your cursor via dynamic synapsis lines. Automatically pauses rendering when scrolled off-screen.
2. **Multi-Role Dynamic Typewriter**: Cycles through key technical specializations (*Software Developer*, *AI / ML Engineer*, *Agentic RAG Specialist*, *Full Stack Developer*, *Competitive Programmer*).
3. **Cyber Grid & Ambient Cursor Spotlight**: Radial-masked dot matrix grid and a subtle ambient cursor spotlight for deep visual immersion.
4. **Interactive Skill Filtering**: Instant client-side filtering across *Languages*, *Web & Mobile*, *AI & ML*, and *Databases & Tools*.
5. **Scroll-Driven Cubic Animated Counters**: Numerical stats (`700+`, `8.47`, `2x`, `4+`) smoothly count up when scrolled into view.
6. **3D Perspective Mouse Tilt**: Interactive 3D depth tilt on project cards and glassmorphic profile glow on hover.
7. **One-Click Quick Copy with Floating Toast**: Instant clipboard copy for contact details with a glassmorphic checkmark confirmation toast, plus direct `mailto:` / `tel:` triggers.
8. **Top Reading Progress Bar & Scrollspy**: Real-time reading depth bar and active section navbar tracking.

## 🏃 Quick Start / Running Locally

Because this is a pure frontend static portfolio, **no backend server or package installation is required**.

### Option 1: Direct File Opening
Double-click `index.html` or open it with any web browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local Static Server
If you prefer running a local server:

**Using Python:**
```bash
python -m http.server 8000
```
Then visit: `http://localhost:8000`

**Using Node / npx:**
```bash
npx serve .
```

## 🚀 Deployment

This site can be deployed instantly for free on any static host:

- **GitHub Pages**:
  1. Go to your GitHub repository **Settings** > **Pages**.
  2. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
  3. Select branch `main` and folder `/ (root)`, then click **Save**.
- **Vercel**: Run `vercel` or connect your GitHub repo on [vercel.com](https://vercel.com).
- **Netlify**: Drag-and-drop the project folder or connect via GitHub on [netlify.com](https://netlify.com).
